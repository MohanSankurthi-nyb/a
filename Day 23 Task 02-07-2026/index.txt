Media queries used to make a website responsive,meaning the webpage can adapts its layout and design based on 
devices screen size,resolution or orientation
Purpose :
1.create a responsive designs - adjust the layout for different devices
2.change layout based on screen size.
3.Adjust typography-inc or dec font sizes depending on the devices

common breakpoints:
Device type                  Typical Screen Width
Mobile Phones                Up to 767px
Tablets                      768px - 1023px
Laptops                      1024px - 1439px
Desktop screens              1440px and above
